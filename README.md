# 🚗 Ponto A

> Landing page de demonstração para um aplicativo fictício de mobilidade urbana.

O **Ponto A** é um projeto de front-end que apresenta uma empresa de transporte por aplicativo: quem somos, serviços, botões de download, guia de uso e termos de uso.

> ⚠️ **Projeto de demonstração.** Marca, logotipo, contatos e textos são fictícios e não representam nenhuma empresa real. Todas as imagens foram geradas especificamente para este projeto.

![Prévia do site](img/preview.png)

## Funcionalidades
 
- **Sobre nós**: missão e apresentação da empresa
- **Download do app**: botões para Google Play e Apple Store
- **Serviços**: modalidades *Comum* (até 4 passageiros) e *Pet* (viagens com animais de estimação)
- **Como usar o aplicativo**: passo a passo em modal, do cadastro à confirmação da corrida
- **Termos de uso**: texto completo em modal
- **Contato e suporte**: telefone, e-mail, Instagram e atendimento via WhatsApp
- **Menu responsivo**: navegação em barra no desktop e menu lateral no mobile

## Tecnologias

- HTML5
- CSS3 
- JavaScript
- [Bootstrap Icons](https://icons.getbootstrap.com/) 
- [Google Fonts: Lato](https://fonts.google.com/specimen/Lato) 
 
Não há frameworks, build ou dependências para instalar.
